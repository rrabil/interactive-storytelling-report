# Promo images

Images for sharing the report, not used on the page itself (Quarto doesn't copy them into the site).

- `pdf-to-web.png` (3200×1800): before/after for the blog post. The 2012 PDF pages lead to the 2026 site on desktop and phone.
- `linkedin-portrait.png` (1080×1350): portrait card for a LinkedIn image post.
- `link-card-landscape.png` (1200×630): copy of `og-image.png`, the link-preview card the site serves. Edit `og-image.png` at the repo root; it's the one the site uses.

The HTML sources these were rendered from stay local in `_source/` and `_notes/`, rendered with headless Edge.
